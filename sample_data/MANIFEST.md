## Edge cases (`edge_cases/`)

| File | Contents | Expected tool behaviour |
|---|---|---|
| `corrupt.pdf` | `%PDF-1.7` header followed by 512 garbage bytes | `read_file` / `search_in_file` fail with `EXTRACTION_FAILED` |
| `empty.txt` | Zero bytes | Success with empty `content` |
| `no_text_layer.pdf` | Valid 1-page PDF containing only drawn shapes | Success; `content` empty/whitespace, `pages` = 1 |
| `cp1252_resume.txt` | Short resume encoded as cp1252 (é, ’, —) - invalid UTF-8 | Success via encoding fallback; metadata `encoding` = `cp1252` |
| `unsupported.xlsx` | 68 raw bytes with an unsupported extension | Fails with `UNSUPPORTED_FORMAT` |
